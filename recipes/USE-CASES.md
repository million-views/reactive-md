## What Are These Recipes?

This collection provides **practical templates and examples** for using Reactive MD to accomplish real development and product work. Each recipe demonstrates how to leverage Reactive MD's instant component preview capabilities for specific jobs.

**Why recipes?** Because Reactive MD isn't just a code viewer - it's a tool that helps you **get work done faster** by eliminating the context-switching between editor and browser.

---

## Jobs You Can Accomplish

### 1. Create Product Specifications

**The Job**: Define what to build and why it matters.

**How Reactive MD Helps**: Write PRDs with live, interactive examples that stakeholders can actually experience.

**Recipe Categories**:
- **PRD Templates** (`prd-templates/`): Structured templates for feature specs, user flows, competitive analysis, and A/B test proposals
- **Case Studies** (`case-studies/`): Complete mini-PRDs showing full product concepts

**Example Workflow**:
1. Start with a PRD template
2. Add interactive wireframes using Reactive MD
3. Include live component demos in your spec
4. Get stakeholder feedback without leaving your editor

---

### 2. Design User Interfaces

**The Job**: Create visual concepts and page layouts.

**How Reactive MD Helps**: Design interfaces with instant visual feedback, no build setup required.

**Recipe Categories**:
- **Wireframes** (`wireframes/`): Quick visual concepts for landing pages, dashboards, onboarding flows, settings pages, and empty states
- **Design Patterns** (`design-patterns/`): Reusable UI patterns for navigation, data tables, modals, cards, and feedback states

**Example Workflow**:
1. Sketch wireframes with markdown and JSX
2. Preview layouts instantly with `Cmd+K P`
3. Iterate on spacing, colors, and interactions
4. Share clickable prototypes with your team

---

### 3. Document User Journeys

**The Job**: Map out complete user experiences and flows.

**How Reactive MD Helps**: Create interactive journey documentation that users can actually walk through.

**Recipe Categories**:
- **User Journeys** (`user-journeys/`): Multi-step narratives for signup flows, checkout processes, search-to-purchase, and support tickets

**Example Workflow**:
1. Use journey templates to outline user paths
2. Add interactive steps with working components
3. Test the flow end-to-end in Reactive MD
4. Validate UX assumptions before development

---

### 4. Prototype Features

**The Job**: Validate ideas and explore possibilities quickly.

**How Reactive MD Helps**: Prototype features with real components, instant feedback, and no configuration overhead.

**Recipe Categories**:
- **Feature Concepts** (`feature-concepts/`): Specific feature ideas with interactive demos for notifications, dark mode, infinite scroll, drag-and-drop, and real-time updates

**Example Workflow**:
1. Pick a feature concept template
2. Customize the interactive demo
3. Test user interactions and edge cases
4. Decide whether to build or iterate further

### 5. Build Design Systems

**The Job**: Create and maintain reusable component libraries.

**How Reactive MD Helps**: Develop components with immediate visual feedback, then document them with live examples.

**Recipe Categories**:
- **All categories**: Design systems benefit from PRD templates, wireframes, patterns, and case studies

**Example Workflow**:
1. Define component APIs in markdown
2. Create live examples showing variants and states
3. Document usage patterns with interactive demos
4. Maintain component documentation that stays current

---

### 6. Write Technical Documentation

**The Job**: Create documentation that developers can learn from and trust.

**How Reactive MD Helps**: Write docs with code examples that actually run and render.

**Recipe Categories**:
- **All categories**: Technical docs often include wireframes, user journeys, and feature concepts

**Example Workflow**:
1. Structure your documentation with clear sections
2. Add `jsx live` code fences for interactive examples
3. Include working components that readers can modify
4. Keep examples current and testable

## Getting Started

1. **Browse the recipe categories** above to find templates for your current job
2. **Open any `.md` file** in VS Code with Reactive MD installed
3. **Use `Cmd+K P`** (Mac) or `Ctrl+K P` (Windows/Linux) to open Interactive Preview
4. **Modify the JSX** in code fences to customize examples
5. **See changes instantly** - no build step required
